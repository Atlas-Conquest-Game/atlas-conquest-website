# Metagame Feature Summary

Date: 2026-05-16

## Goal

Add an MTGGoldfish-style metagame page for Atlas Conquest that groups real played decks into archetypes, then shows each archetype's metagame prevalence, winrate, commander, and representative cards.

## Backend/Data Pipeline

Added archetype generation to `scripts/pipeline/aggregation.py`.

The pipeline now:

- Groups decks by commander.
- Builds a per-commander card co-occurrence graph.
- Uses a dependency-free Louvain-style local moving algorithm to find card packages.
- Assigns decks to package combinations to create archetype rows.
- Computes archetype deck count, wins, winrate, commander share, metagame share, representative cards, and signature cards.

New generated output:

- `site/data/archetypes.json`

The archetype card output was tuned after review:

- `cards` is now the representative display list.
- `key_cards` remains a smaller differentiator/signature list.
- `total_cards_seen` records the full number of observed cards before trimming.
- `card_display_threshold` is currently `0.25`.
- `card_display_minimum` is currently `15`.

This means cards shown in an archetype must either appear in at least 25% of decklists in that archetype, or be part of the top 15 cards for diffuse archetypes.

## Frontend

Added a new page:

- `site/metagame.html`
- `site/js/metagame.js`
- `site/css/metagame.css`

The page supports:

- Expandable archetype tabs.
- Sorting by prevalence or winrate.
- Filtering by commander.
- Displaying metagame share, commander share, winrate, and deck count before expansion.
- Displaying card prevalence and average copies after expansion.
- Card image preview on hover, using the existing `assets/cards/<slug>.jpg` pattern.

Navigation updates:

- Added Metagame to the primary nav.
- Added Metagame to the analytics sub-nav.
- Updated `site/js/shared.js` so Metagame has its own active nav state.

## Data Generated

Using local AWS credentials from `.env.txt`, the pipeline fetched and processed real data:

- `3,616` games processed.
- `7,232` player-deck entries.
- `104` archetypes.
- `16` commanders.

The pipeline generated:

- Updated `site/data/*.json` analytics files.
- New `site/data/archetypes.json`.
- Two new card preview assets:
  - `site/assets/cards/lightbound-martyr.jpg`
  - `site/assets/cards/rhea-morning-saint.jpg`

`.env.txt` was added to `.gitignore` so local credentials are not accidentally committed.

## Example Tuning Result

Initial issue:

- `Quickling / Poison Spray` displayed only 12 cards, and its naming cards were not in the expanded table.

First fix:

- Displayed the full observed card list.
- This made the archetype representative, but too noisy.

Final tuning pass:

- Applied the 25% inclusion threshold with a minimum of 15 displayed cards.
- `Quickling / Poison Spray` now displays 31 representative cards out of 65 observed cards.
- `Quickling` and `Poison Spray` are both included.
